# 高级语言程序设计实验 02：C++ 简单程序设计

## 实验目的

掌握 C++ 简单程序的编写、编译与运行，熟悉分支结构与循环结构的使用。

## 实验内容

本次实验共 8 道编程练习题：

1. Q1：企业奖金分段提成计算（累进提成）
2. Q2：根据电影打分输出评价
3. Q3：判断一个整数是否为回文数
4. Q4：输出所有三位水仙花数
5. Q5：求 a + aa + aaa + … 数列前 n 项的和
6. Q6：输出 9×9 乘法口诀表
7. Q7：古典兔子问题，求 20 个月每月兔子总数
8. Q8：猴子吃桃问题，倒推第一天共摘了多少桃子

## 文件说明

- Q1.cpp ~ Q8.cpp：8 道题的源代码，每题一个文件

## 运行环境

- macOS，g++ 编译器

## 运行方法

以第 1 题为例：

g++ Q1.cpp -o Q1 && ./Q1
